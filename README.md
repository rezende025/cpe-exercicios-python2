# Computação para Engenharia (CPE) - UnB

**Repositório de Exercícios Práticos em Python - Controle de Fluxo**  
Este repositório reúne os exercícios práticos desenvolvidos durante a disciplina, com foco em algoritmos e estruturas de controle de fluxo.

## 📝 Descrição
O projeto contém 30 scripts autônomos em Python, focados em consolidar os seguintes conceitos fundamentais:
- Estruturas condicionais (`if`, `elif`, `else`, `match-case`)
- Laços de repetição (`while`, `for`)
- Controle de laços (`break`, `continue`)
- Manipulação de strings e conversão de tipos básicos
